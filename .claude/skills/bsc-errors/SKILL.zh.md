# BiSheng C 错误码技能

## 1. 错误码方案

BSC 错误使用 `BSC-Exxxx`（错误）和 `BSC-Wxxxx`（警告）格式，按类别分组：

| 范围 | 类别 | 描述 |
|-------|----------|-------------|
| BSC-E01xx | 所有权 | 移动后使用、未初始化、赋值、转换、内存泄漏 |
| BSC-E02xx | 借用检查 | 生命周期、多次借用、借用期间赋值 |
| BSC-E03xx | 安全区域 | 在 `_Safe` 函数/块中禁止的操作 |
| BSC-E04xx | 可空性 | 解引用/传递/返回/转换可空指针 |
| BSC-E05xx | Traits | 未定义的 trait、未实现的函数、类型冲突 |
| BSC-E06xx | 拥有的结构体/析构函数 | 结构体标记、析构函数、成员问题 |
| BSC-E07xx | 类型系统 | `_Owned`/`_Borrow` 限定词冲突、不兼容的转换 |
| BSC-E08xx | 异步 | `_Async`/`_Await` 使用 |
| BSC-E09xx | 泛型/常量表达式 | 泛型函数问题、constexpr 限制 |
| BSC-E10xx | 解析级别 | BSC 特定的语法错误 |
| BSC-E11xx | 成员函数 | 实例成员、属性 |
| BSC-E12xx | 操作符重载 | 重载限制 |

## 2. 诊断抑制标志

使用命令行中的 `-Eno-<identifier>` 或源代码中的 `#pragma GCC diagnostic ignored "-E<identifier>"` 来抑制：

```
bsc-safety-check              # 所有 BSC 安全检查
├── bsc-ownership             # 所有所有权检查
│   ├── use-moved-owned       #   移动后使用
│   ├── use-uninit-owned      #   使用未初始化
│   ├── assign-owned          #   赋值给拥有的变量
│   ├── cast-owned            #   转换拥有的变量
│   └── check-memory-leak     #   内存泄漏
├── bsc-borrow                # 所有借用检查
│   ├── assign-borrowed       #   借用期间赋值
│   ├── move-borrowed         #   借用期间移动
│   ├── use-mutably-borrowed  #   可变借用期间使用
│   ├── repeated-borrow       #   多次可变借用
│   ├── return-local-borrow   #   返回局部引用
│   └── short-life-borrow     #   生命周期太短
└── bsc-nullability           # 所有可空性检查
    ├── deref-nullable        #   解引用可空指针
    ├── pass-nullable         #   传递可空参数
    └── return-nullable       #   返回可空指针
```

> 有关完整层次结构和使用示例，请参见 `bsc-compile` 技能。

## 3. AI 友好数据库

对于 LLM/IDE 集成，`errors/ai/` 目录包含：

- `bsc-errors.json` — 所有错误的结构化 JSON 数据库，包含原因、修复策略、代码示例和关键字
- `bsc-errors.schema.json` — JSON schema
- `error-code-mapping.json` — 将诊断名称映射到错误码

## 4. 常见错误快速参考

### 所有权（BSC-E01xx）

| 编码 | 消息 | 修复 |
|------|---------|-----|
| E0101 | 使用已移动的值 | 在转移所有权之前使用变量 |
| E0104 | 使用未初始化的值 | 在使用前初始化 |
| E0106 | 赋值给 _Owned 值 | 先释放旧值，或使用新变量 |
| E0115 | 无效的 _Owned 值转换 | 不要转换仍持有所有权的 _Owned 指针 |
| E0118 | 内存泄漏（拥有的变量未释放） | 在作用域结束前释放、返回或转移 |
| E0119 | 字段内存泄漏 | 在作用域结束前释放 _Owned struct 字段 |
| E0126 | 临时变量内存泄漏 | 捕获返回 _Owned 的函数的返回值 |

### 借用（BSC-E02xx）

| 编码 | 消息 | 修复 |
|------|---------|-----|
| E0201 | 不能赋值给借用的变量 | 在修改前结束借用 |
| E0202 | 不能移出借用的变量 | 在移动前结束借用 |
| E0203 | 不能使用可变借用的变量 | 改为通过借用指针读取 |
| E0204 | 不能多次可变借用 | 一次只能有一个 `&_Mut` |
| E0207 | 不能返回对局部变量的引用 | 按值返回或使用 `_Owned` 堆分配 |
| E0208 | 值生命周期不够长 | 确保被借用的值比借用活得更久 |

### 安全区域（BSC-E03xx）

| 编码 | 消息 | 修复 |
|------|---------|-----|
| E0301 | 安全区域中禁止的不安全操作 | 包装在 `_Unsafe { }` 块中或使用安全替代 |
| E0302 | 无效的 _Safe/_Unsafe 声明位置 | 将限定词放在函数声明或块语句上 |
| E0303 | 安全区域中的联合体成员访问 | 将联合体访问包装在 `_Unsafe { }` 块中 |
| E0304 | 安全区域中禁止的转换 | 将转换包装在 `_Unsafe { }` 中或传递正确的类型 |
| E0307 | _Safe 函数中禁止的操作 | 将操作移到 `_Unsafe` 块中 |
| E0308 | 安全区域中的可变全局变量 | 使全局变量为 `const` 或在安全区域外定义 |

### 可空性（BSC-E04xx）

| 编码 | 消息 | 修复 |
|------|---------|-----|
| E0401 | 不能解引用可空指针 | 在解引用前添加空检查 |
| E0402 | 不能传递可空指针参数 | 在调用前用空检查保护 |
| E0403 | 不能返回可空指针类型 | 添加空检查或将返回类型改为 `_Nullable` |
| E0406 | Nonnull 被可空赋值 | 在赋值前用空检查保护 |
| E0407 | _Nonnull 指针必须初始化 | 在声明时初始化 |

> 有关每个类别的详细文档，请参见 `errors/` 目录。
> 有关常见修复，请参见 `bsc-common-mistakes` 技能。
